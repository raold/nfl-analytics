   File: scripts/xgb_exp2_clustering_fixed.py
   Size: 505 lines
   Purpose: Complete experiment pipeline
   Status: READY TO EXECUTE
   
   What it does:
   - Loads 2018-2024 QB passing yards from PostgreSQL
   - Clusters defenses using K-means (k=4)
   - Creates categorical tier dummies (def_tier_1 to def_tier_4)
   - Trains XGBoost model
   - Evaluates on 2025 test set
   - Saves results to models/xgboost/

IMPORTANT NOTES
================================================================================

1. EXECUTION REQUIREMENTS:
   - PostgreSQL running on localhost:5544
   - Database: devdb01 with ml.model_features table
   - Python packages: pandas, sklearn, xgboost, sqlalchemy
   - RAM: ~2GB
   - Time: ~20 minutes

2. DATA INTEGRITY:
   - Script prevents data leakage (clustering only on training data)
   - Train/test split is temporal (2018-2024 vs 2025)
   - No look-ahead bias in features
   - All features lagged appropriately

3. SUCCESS CRITERIA:
   - MAE < 40.20 yards (beat v2 baseline)
   - Model saves to xgb_exp2_clustering.json
   - Feature importance shows tier dummies ranked
   - Feature importance available in CSV

4. FAILURE HANDLING:
   - If MAE >= 40.20, that's expected (experiments fail)
   - Keep v3.1 (continuous features work)
   - Learn from results
   - Try Exp 3, 4, 5 (alternatives ready in framework)

5. PRODUCTION SAFETY:
   - Only integrate into ensemble if MAE < 40.20
   - Register in model registry before using
   - A/B test on live games before full deployment
   - Monitor metrics continuously
