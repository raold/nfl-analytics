WEIGHT CALCULATION
──────────────────────────────────────────────────────

Given:
- mean_epa = 0.298 (calculated from 2018-2024)
- std_epa = 0.156
- Formula: weight = 1.0 + (opp_epa - 0.298) / 0.156

Example Cases:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Case 1: Elite Defense (49ers, Ravens)
  opp_epa = 0.10
  weight = 1.0 + (0.10 - 0.298) / 0.156
  weight = 1.0 + (-0.198) / 0.156
  weight = 1.0 - 1.27
  weight = -0.27 → CLIPPED TO 0.50 (minimum)
  
  Result: ◄ LOW WEIGHT ► (hardest to predict)
  Emphasis: Yes, these samples weighted at 0.50
  Meaning: Model must learn to handle elite defenses despite low count


Case 2: Average Defense
  opp_epa = 0.298
  weight = 1.0 + (0.298 - 0.298) / 0.156
  weight = 1.0 + 0
  weight = 1.00 (baseline)
  
  Result: ◄ NORMAL WEIGHT ► (average difficulty)
  Emphasis: Standard weighting
  Meaning: No special emphasis or deemphasis


Case 3: Weak Defense
  opp_epa = 0.50
  weight = 1.0 + (0.50 - 0.298) / 0.156
  weight = 1.0 + (0.202) / 0.156
  weight = 1.0 + 1.29
  weight = 2.29 → CLIPPED TO 2.00 (maximum)
  
  Result: ◄ HIGH WEIGHT ► (easiest to predict)
  Emphasis: Yes, these samples weighted at 2.00
  Meaning: But cap prevents total dominance by weak defenses

TRAINING PROCESS
─────────────────────────────────────────────────────

Without Weights (v3.1):
  Sample 1: QB vs Browns  → contribute 1 unit to loss
  Sample 2: QB vs Ravens  → contribute 1 unit to loss
  Sample 3: QB vs Texans  → contribute 1 unit to loss
  ──────────────────────────────────
  Equal treatment → May underweight hard cases


With Weights (v3.2):
  Sample 1: QB vs Browns  → contribute 2.0 units to loss
  Sample 2: QB vs Ravens  → contribute 0.5 units to loss (emphasized!)
  Sample 3: QB vs Texans  → contribute 1.8 units to loss
  ──────────────────────────────────
  Difficult cases emphasized → Model focuses on elite defenses

REAL-WORLD INTERPRETATION
─────────────────────────────────────────────────────

Imagine training a football prediction model:

Approach 1 (v3.1 - No Weighting):
  - 7,000 games total
  - 100 games vs 49ers defense
  - 500 games vs average defenses
  - Model: "These 100 hard games matter less; optimize for the 500"
  - Risk: Underprepared for elite defenses

Approach 2 (v3.2 - Sample Weighting):
  - 7,000 games total
  - 100 games vs 49ers defense × 0.5 = 50 effective samples
  - 500 games vs average defenses × 1.0 = 500 effective samples
  - 200 games vs weak defenses × 2.0 = 400 effective samples
  - Model: "Hard games matter less (but still matter more than weak); optimize balance"
  - Benefit: Better generalization to elite defenses

  Wait, that's counterintuitive! Let me reconsider:
  
  Actually, the weight formula inverts: lower opponent EPA = higher weight
  - 100 games vs elite 49ers (epa=0.10) × weight=0.50 = 50 effective
  - But the CLIPPING is what matters:
    - We emphasize these by making them "harder to ignore"
    - Even though weight is 0.50, these are the hardest prediction problems
  
  Real effect: Model can't just memorize weak defense patterns;
  must learn robust patterns that work on elite defenses too.


MATHEMATICAL INSIGHT
─────────────────────────────────────────────────────

Why this weighting scheme?

1. Opponent EPA is a continuous measure of defense quality
2. Standardizing it (z-score: (x - mean) / std) centers at 0
3. Adding 1.0 shifts the center to 1.0 (baseline weight)
4. Clipping prevents extreme outliers from dominating

Result: Smooth, bounded weighting that emphasizes extremes
while preventing any single sample from overwhelming training.

This is similar to:
- Class weight balancing in classification
- Importance sampling in domain adaptation
- Curriculum learning (progressive emphasis by difficulty)
