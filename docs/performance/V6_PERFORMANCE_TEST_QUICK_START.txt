TROUBLESHOOTING:
----------------
If target missed (<2.6x speedup):
1. Check database connection pool health
2. Verify R posterior draws = 500 (not 1000)
3. Profile individual components (state-space, hierarchical, XGB)
4. Check for unexpected I/O operations
5. Verify skills dict conversion (O(1) lookup)

If models fail to load:
1. Check model paths exist
2. Verify model file integrity (not corrupted)
3. Check R packages installed (brms, cmdstanr)
4. Check rpy2 working: python -c "import rpy2; print('OK')"

If database connection fails:
1. Verify PostgreSQL running: pg_isready -h localhost -p 5544
2. Check DB_PASSWORD in .env
3. Test connection: psql -h localhost -p 5544 -U dro -d devdb01
