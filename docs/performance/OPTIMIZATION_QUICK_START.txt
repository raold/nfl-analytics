PHASE 1 IMPLEMENTATION (THIS WEEK)
================================================================================

Step 1: Connection Pooling (10 minutes)
  File: py/backtest/historical_validation_5way.py
  Change: Replace psycopg2.connect() with connection pool

  Before:
    conn = psycopg2.connect(host="localhost", ...)
    df = pd.read_sql_query(query, conn)
    conn.close()

  After:
    conn = self.db_pool.getconn()
    try:
      df = pd.read_sql_query(query, conn)
    finally:
      self.db_pool.putconn(conn)

Step 2: R Model Caching (15 minutes)
  File: py/utils/r_service.py (extend RService class)
  Change: Add load_model() and predict_cached() methods

  At backtest start:
    r_service.load_model('hierarchical', Path('models/hierarchical_v2.rds'))

  For each prediction:
    pred_mean, pred_std = r_service.predict_cached('hierarchical', newdata)
