PERFORMANCE TARGETS
-------------------
Sequential:           ~1 game/sec
Parallel (no cache):  ~10-20 games/sec  (10-20x speedup)
Parallel (w/ cache):  ~50-200 games/sec (50-200x speedup)

BASIC USAGE
-----------
from py.features.feature_loader_parallel import ParallelFeatureLoader

# Initialize
loader = ParallelFeatureLoader(use_redis=True, n_workers=8)

# Extract full season (batch mode)
features_df = loader.extract_season_features(
    season=2024,
    weeks=[1,2,3,4,5]  # List of weeks
)

# Extract specific games (API use case)
games_df = pd.DataFrame({
    'season': [2024, 2024],
    'week': [12, 12],
    'home_team': ['KC', 'BUF'],
    'away_team': ['LAC', 'MIA']
})
features_df = loader.extract_game_features_batch(games_df, use_cache=True)

FEATURE TYPES
-------------
Available feature_types (default: all):
- 'team_offensive':  Team offensive stats (EPA, success rate, pass rate)
- 'team_defensive':  Team defensive stats (EPA allowed, sack rate)
- 'vegas':           Betting lines (spread, total, moneylines)
- 'environmental':   Weather, rest, rivalry, venue
- 'injuries':        Injury load, QB/key position/oline injuries

# Extract subset
features_df = loader.extract_season_features(
    season=2024,
    weeks=[1,2,3],
    feature_types=['vegas', 'environmental']  # Only 2 types
)

-------------------
1. Connection Pooling  (psycopg2.pool):      2-3x faster
2. Batch SQL Queries   (1 query/season):     10-20x faster
3. Redis Caching       (1-hour TTL):         50-200x faster
4. Vectorized Ops      (pandas):             5-10x faster

COMBINED: 10-20x speedup (no cache), 50-200x speedup (with cache)

DATABASE SCHEMA
---------------
Tables:
  - plays:                  ~1.2M rows (team stats source)
  - games:                  ~7,263 rows (vegas + environmental source)
  - mart.team_injury_load:  ~2,798 rows (injury source)

Batch Loading:
  - Single query per feature type
  - WHERE season = %s AND week = ANY(%s)
  - Fetches entire season in 1 query (~256 games)

REDIS CACHE
-----------
Key Format:   features:{season}:{week}:{home}:{away}:{hash}
Example:      features:2024:12:KC:LAC:a8f3e2d1
TTL:          3600 seconds (1 hour)

MONITORING
----------
# Cache hit rate
stats = loader.get_cache_stats()
if stats['hit_rate'] < 0.8:
    logger.warning(f"Low cache hit rate: {stats['hit_rate']*100:.1f}%")

# Memory usage
if stats['memory_used_mb'] > 500:
    logger.warning(f"High cache memory: {stats['memory_used_mb']:.0f} MB")
    loader.clear_cache(pattern="features:*")

# Performance metrics
import time
start = time.time()
features_df = loader.extract_season_features(season=2024, weeks=[1,2,3])
throughput = len(features_df) / (time.time() - start)
logger.info(f"Throughput: {throughput:.1f} games/sec")

TROUBLESHOOTING
---------------
Low throughput (<10 games/sec):
  → Increase n_workers: loader = ParallelFeatureLoader(n_workers=16)
  → Check Redis is running: redis-cli ping
  → Check DB latency: psql -h localhost -p 5544 -d devdb01

Cache not working (0% hit rate):
  → Check Redis connection: stats = loader.get_cache_stats()
  → Verify cache keys: cache_key = loader._make_cache_key(2024, 12, 'KC', 'LAC')
  → Increase TTL: loader.CACHE_TTL = 86400  # 24 hours

High memory usage (>1 GB):
  → Clear old seasons: loader.clear_cache(pattern="features:2020:*")
  → Reduce TTL: loader.CACHE_TTL = 1800  # 30 minutes
