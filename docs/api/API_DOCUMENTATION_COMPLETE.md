## Maintenance

### Keeping Documentation Current

FastAPI auto-generates OpenAPI specs from:
- Pydantic models (request/response schemas)
- Function docstrings (descriptions)
- Type hints (validation rules)
- Decorators (HTTP methods, tags)

To update documentation:
1. Update Pydantic models if schemas change
2. Update function docstrings if behavior changes
3. Add examples to Pydantic `Config.schema_extra`
4. FastAPI automatically regenerates `/openapi.json`

### Documentation Checklist for New Endpoints

- [ ] Add comprehensive docstring with Args, Returns, Raises
- [ ] Define Pydantic request/response models
- [ ] Add schema_extra with examples to models
- [ ] Add proper HTTP status codes
- [ ] Add endpoint tags for grouping
- [ ] Add error handling documentation
- [ ] Update `/docs/api/API_REFERENCE.md` manually
- [ ] Update `/docs/api/ENDPOINT_INVENTORY.md`
- [ ] Test in Swagger UI (`/docs`)
