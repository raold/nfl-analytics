# Line Movement and Closing-Line Value, 2020-2024 (2026-10-24)

`public.odds_history` is the one dataset in this project that nflverse cannot replace: The Odds
API historical snapshots for 2020-2024, from up to 25 books, starting a week or more before
kickoff and ending a few hours before it. This note rebuilds the snapshot times, cleans the
rows, and reports what the panel says about line movement, closing-line value (CLV) and line
shopping.

**Aggregates only.** The Odds API terms forbid redistributing the data as a standalone product,
so the row-level panel stays in `backups/local/odds_history_panel/` (gitignored), with its own
README covering columns, flags and the licence. Every number below comes from
[`results.md`](results.md) / [`results.json`](results.json), generated by
`scripts/odds_history_panel.py` (10,000-draw week-block bootstrap, seed 0; deterministic).

## Findings

- **The close is efficient; what a bettor gains is the price.** In the 582 games whose consensus
  moved by 1 point or more between the earliest multi-book snapshot (median 176 h before kickoff)
  and the close, the side the line moved toward covered **50.4%** at the closing line (95% CI
  46.2-54.8) but **59.2%** (55.2-63.2) at the early line. The 8.7-point gap (6.6-11.0) is what
  holding a number 2.4 points better than the close was worth on average. This is not a strategy:
  which way a line will move is only known afterwards.
- **Lines sharpen during the week and barely move on game day.** The consensus sits a mean
  1.61 points from the close 7-14 days out, 1.14 at 4-7 days, 0.75 at 2-4 days and 0.40 in the
  last 6 hours. Against the final margin, the game-day consensus (median 4 h before kickoff) is as
  accurate as the close (MAE 10.040 vs 10.059).
- **Shopping ~15 books a few hours before kickoff gains about a third of a point per side,**
  worth about 1.3 percentage points of ATS win probability (graded on results: 51.5% vs 50.0%).
  That is still short of the 52.4% needed at -110.
- **Coverage is biased.** No Rams game and no game that kicks off on the next UTC date
  (20:00 EDT / 19:00 EST or later, e.g. Sunday, Monday and Thursday night) has a game-day snapshot.
  Two matcher bugs in the backfill discarded rows the API returned. In practice this is a panel of
  daytime games.
- **There are no snapshots for 2025 or 2026.**

## Data and timing

`scripts/backfill_historical_odds.py` (Dec 2025) made two historical API calls per game date and
stored each call's name in `market_type`. Neither is an opening or a closing line:

| label | requested snapshot | in true time |
|---|---|---|
| `closing` | MIN(`games.kickoff` on that date) - 30 min | `kickoff` then held Eastern wall-clock time labelled UTC, so 4.5 h (EDT) or 5.5 h (EST) before the first kickoff |
| `opening` | 14:00 UTC on the game date | 10:00 EDT / 09:00 EST, so after kickoff for the 09:30 EDT London games |

Each call returns every listed game, so a game also collects snapshots from the calls of earlier
game dates (a week or more ahead, often with few books). There is no true opener, and the close
used here is `games.spread_close` (nflverse). No snapshot time was stored (`captured_at` is the
insert time).

**Reconstruction, without API calls.** Rows split into API calls where `captured_at` jumps by more
than 0.2 s (308 calls per label at any threshold from 0.05 s to 0.5 s). Each call is matched to the
first scheduled request at or after its newest `last_update`, because the API returns the latest
snapshot at or before the requested time. The schedule is recomputed from the pre-repair kickoffs
(`backups/local/games_before_repair_20261024.csv`). For all 1,408 games of 2020-2024 these are
identical to `games` in `backups/local/nfl_analytics_20251208_odds_complete.dump` (private; it
was untracked from `backups/` on 2026-10-25), taken right after the backfill, so they are the
values the backfill read.

| check | `closing` | `opening` |
|---|---|---|
| requests scheduled (game dates) | 309 | 309 |
| API calls found | 308 | 308 |
| request with no rows | 2022-02-13 (Super Bowl LVI, `2021_22_LA_CIN`: a Rams game, see Coverage) | same date |
| calls mapped to the same request | 0 | 0 |
| rows updated after their request time | 0 | 0 |
| request minus newest update in the call, minutes (min / median / p95 / max) | 4.3 / 4.8 / 10.5 / 131.1 | 4.4 / 5.0 / 10.7 / 11.7 |
| runs in capture order | 2: 10 calls (the first 10 dates of 2024), then 298 calls that skip those dates | 1 |

The script stops if any of these checks fails. The survey's proxy (newest `last_update` per game
and label) agrees: for all 2,122 (game, label) pairs the newest request is 4.4-13.1 minutes after
the newest update; `opening` is the later pull in 94.9% of games (median +1.50 h); and the newest
`opening` / `closing` updates are a median 4.1 h / 5.7 h before kickoff. One `closing` call
(2023-10-12 19:45 UTC, 274 rows, 20 games) holds data about 2 h older than its request and is
flagged `flag_stale_call`.

## Cleaning

| step | rows | games | rule |
|---|---|---|---|
| `market_type = 'game_lines'` dropped | 32 | 8 | 31 rows sit on 7 2024 game_ids but were recorded 8,070-10,756 h after those games, within 10 days of the same matchups in 2025 weeks 14-15; their writer is not in the repo |
| `flag_inplay` | 120 | 11 | request or `last_update` after the true kickoff: the 14:00 UTC call on the 09:30 EDT (London) games |
| `flag_spread_price` | 453 | 104 | a zero price (48 rows, pointsbetus) or an alternate-line pair, i.e. a side above +125 or below -200 (405 rows, 392 of them betmgm 2020) |
| `flag_spread_outlier` | 75 | 27 | normal price but at least 3 points from the same call's median line (3+ books); 26 are betus 2023 |
| `flag_total_price` / `flag_moneyline_price` | 428 / 24 | 94 / 19 | the same price rules for totals; zero moneylines |
| clean spread quotes | 110,189 | 1,061 | none of the spread flags |

The price rule is set by the data: alternate-price quotes sit a median 9.0 points from the same
call's median line (p5 4.5), while main-price quotes sit a median 0.0 (p95 0.5).

**Sign.** `line_home = -home_spread` converts the sportsbook home line to the nflverse sign
(expected home margin, positive = home favored). Game-day consensus vs `spread_close`: MAE 0.407,
45.1% exact, 94.2% within 1 point, correlation +0.994. Without the flip the MAE is 10.486 and the
correlation is -0.994. The gap is largest in 2020 (0.572) and smallest in 2024 (0.279).

Both holes come from `find_game_id` (`scripts/backfill_historical_odds.py:205-244`). It mapped
'Los Angeles Rams' to `LAR` while `games` uses `LA`. It also compared the API's UTC commence
date with `DATE(kickoff)`, which was the ET date, so every game starting at 20:00 EDT / 19:00 EST
or later failed to match. The matcher could never accept these games, so whatever the API returned
for them was dropped (no raw responses were stored). The 10 night games that do have odds show
they were in the feed: they matched only in early snapshots (the latest at least 82 h before
kickoff), in which the API's commence time must still have fallen on the ET date. Filling the
holes would take paid quota and a fixed matcher. Every analysis below uses the 1,051 games that
have a game-day consensus: at least 5 books, at most 12 h before kickoff.

### (a) Line accuracy against the final margin

1,051 games, the same games for every line.

| earliest snapshot with at least 5 books | 173.5 | 10.183 | +0.124 (+0.001 to +0.251) |
| latest pre-kickoff snapshot (game day) | 4.0 | 10.040 | -0.019 (-0.061 to +0.021) |

### (b) How much and when lines move

Distance between the snapshot consensus (5+ books) and the close, by hours before kickoff:

| hours before kickoff | snapshots | games | mean \|line - close\| | moved >= 1 | moved >= 2 | moved >= 3 |
|---|---|---|---|---|---|---|
| 0-6 | 1,313 | 733 | 0.401 | 14.5% | 2.8% | 0.8% |
| 6-12 | 766 | 460 | 0.457 | 16.7% | 5.1% | 1.2% |
| 12-48 | 390 | 212 | 0.747 | 33.6% | 13.1% | 4.1% |
| 48-96 | 1,830 | 891 | 0.745 | 32.8% | 10.6% | 4.5% |
| 96-168 | 1,852 | 898 | 1.136 | 50.0% | 21.4% | 10.1% |
| 168-336 | 1,881 | 581 | 1.607 | 60.4% | 34.8% | 19.6% |
| 336+ | 77 | 23 | 3.753 | 81.8% | 63.6% | 44.2% |

Per game, the earliest 5+-book consensus (median 173.5 h out) is a median 1.0 point from the close
(mean 1.44; p90 3.5). 55.4% of games move 1 point or more, 30.5% at least 2 and 15.8% at least 3.
Most of the movement is over by game day. The game-day consensus equals the close in 45.1% of
games and is 1 point or more away in 14.7%.

### (c) What closing-line value is worth

For each game whose consensus moved at least the threshold between the early snapshot and the
close, take the side the line moved toward. Grade it at the early line and at the close (pushes
excluded; ROI at -110).

| early line, move | games | at the early line | at the close | difference, pp (95% CI) |
|---|---|---|---|---|
| **earliest 5+ books, >= 1 pt (main)** | 582 | 342-236-4, **59.2%** (55.2-63.2), ROI +13.0% | 286-281-15, **50.4%** (46.2-54.8), ROI -3.7% | +8.7 (+6.6 to +11.0) |
| earliest 5+ books, >= 0.5 pt | 852 | 56.0% (52.5-59.3) | 49.3% (45.6-52.9) | +6.7 (+5.1 to +8.3) |
| earliest 5+ books, >= 2 pts | 321 | 58.6% (53.2-64.1) | 47.9% (41.9-53.8) | +10.7 (+7.6 to +13.9) |
| earliest 5+ books, >= 3 pts | 166 | 65.5% (57.6-73.0) | 50.0% (41.6-58.3) | +15.5 (+10.4 to +20.6) |
| earliest snapshot, any books, >= 1 pt | 673 | 64.2% (60.8-67.5) | 52.0% (48.4-55.6) | +12.2 (+9.9 to +14.5) |
| earliest 3+ books, >= 1 pt | 615 | 61.3% (57.6-65.2) | 50.8% (47.0-54.8) | +10.5 (+8.4 to +12.7) |
| main, without 2020 | 463 | 59.4% (54.7-64.2) | 50.2% (45.5-55.1) | +9.2 (+6.9 to +11.6) |
| survey definition (median of each book's first quote) | 562 | 328-226-8, 59.2% (55.3-63.1) | 281-267-14, 51.3% (47.0-55.6) | +7.9 (+5.8 to +10.2) |

How to read it:

- **At the close the moves carry no information.** The side the market moved toward covers about
  half the time against the closing number in every row (47.9-52.0%, all CIs spanning 50%). Line
  moves do not keep going, which is what an efficient close implies.
- **At the early number the same bets win 56.0-65.5%.** The gap grows with the size of the move,
  from +6.7 points at 0.5+ to +15.5 at 3+. This measures the value of getting a better number than
  the close, and it is the benchmark for CLV: here, holding a number a mean 2.4 points better than
  the close was worth 59.2% against the spread. It is not a betting rule, because the direction of
  the move is unknown while the early line is available.
- The any-book early lines are earlier and thinner (median 246 h before kickoff), move more
  (mean 3.2 points) and show a larger gap (+12.2). Dropping 2020, the season whose consensus
  differs most from the close, changes nothing.

### (d) Book dispersion: best available line vs the consensus at the same snapshot

| measure | game-day snapshot | earliest 5+-book snapshot before game day |
|---|---|---|
| snapshots (games) | 1,051 | 1,025 |
| median hours before kickoff / median books | 4.0 / 15 | 173.5 / 10 |
| books disagree / range >= 1 point | 86.4% / 32.3% | 78.2% / 28.1% |
| best line better than the consensus, points per side (mean) | 0.343 | 0.311 |
| sides with a gain >= 0.5 / >= 1 point | 54.0% / 8.8% | 47.2% / 9.1% |
| implied ATS win-probability gain per side | +1.30 pp | +1.14 pp |
| price cost of the best quote vs -110 | +0.07 pp | -0.28 pp |
| the same gain, net of the quoted price (vs the consensus at -110) | +1.22 pp | +1.41 pp |
| median price of the best quote (decimal) / share at -110 or better | 1.91 (-109.9) / 65.8% | 1.91 (-109.9) / 79.7% |
| realized ATS at the best line vs the consensus (both sides) | 51.5% (51.1-51.9) vs 50.0% | 51.0% (50.7-51.4) vs 50.0% |

The implied gain prices each quote with the historical distribution of home margins in games
whose closing line was within half a point of the consensus (1999-2025, 7,276 games, both
orientations pooled; the window widens for rare lines). That captures key numbers: buying a half
point from 3.5 to 3 is worth +4.97 pp, from 3 to 2.5 +4.59 pp, from 7 to 6.5 +3.21 pp, but from
1.5 to 1 only +0.96 pp. The realized rates check this against the actual results with no model.

How to read it: the snapshots are hours before kickoff, not at the close. Even at the best of about
15 books, a bet with no information wins 51.5%, still short of the 52.4% needed at -110. The best
line usually comes at an ordinary price (median decimal 1.91, i.e. -109.9), so on average the price
does not give the gain back. Prices are stored as int(American) of the API's two-place decimal odds,
truncated toward zero, so a stored -109 is a 1.91 quote, not a better-than-standard -109
(see "Prices" in [results.md](results.md)). For scale, (c) and (d) price a point about the same: 8.7 pp for a 2.4-point CLV in (c),
1.3 pp for 0.34 points in (d).

### (e) 2025 and 2026

`odds_history` has no `opening` / `closing` rows after the 2024 season (the only later row is a
dropped 2025 `game_lines` row), and `games` has no 2026 rows. There is no working source:
`ODDS_API_KEY` is not set, and `nfl_analytics/ingest_odds_smart.py` never stores what it fetches.
nflverse still publishes closing spreads, totals and moneylines, so a future bet can be graded for
CLV against the close if the line at bet time is recorded.

## Caveats

- **Coverage.** No Rams games and no night games (see Coverage). Primetime markets attract more
  money and may close differently, so none of these numbers should be read as covering them.
- **Reconstructed timing.** `request_at` is the requested snapshot time. The data show the market
  a few minutes earlier (the newest update in a call is a median 4.8-5.0 minutes before it), and
  one flagged call is about 2 h stale.
- **No true opener.** "Early" means the earliest snapshot in which the game appears, which
  depends on the backfill's game-date calls. With any number of books it can be months ahead
  (p90 2,260 h). The main definition requires 5 books (median 173.5 h; p90 246 h). In 26 games
  even that snapshot is on game day.
- **The close is nflverse's.** `spread_close` is a single published number. The game-day consensus
  is a median of books about 4 h earlier; the two differ by 3 points or more in 10 games.
- **One sample.** Five seasons of daytime games, with week-block bootstrap intervals. The
  sensitivity rows reuse the same games, so they are not independent confirmations.
- **Line shopping is an upper bound.** The best line is taken across all 25 books in the feed,
  including offshore books many US bettors cannot use, and ignores limits.

## Reproduce

Needs devdb01 (read in a read-only session) and the private before-image of the 2026-10-24
games repair:

```bash
uv run python scripts/odds_history_panel.py
# optional: confirm the backfill read the pre-repair kickoffs
docker exec -i nfl-analytics-pg-1 pg_restore -a -t games -f - \
    < backups/local/nfl_analytics_20251208_odds_complete.dump > /tmp/games_20251208.copy
uv run python scripts/odds_history_panel.py --dump-games-copy /tmp/games_20251208.copy
```

The script writes the private panel to `backups/local/odds_history_panel/`
(`odds_history_panel_2020_2024.parquet`, one row per quote; `odds_history_snapshots_2020_2024.parquet`,
consensus and best quotes per game and call; `coverage_2020_2024.csv`; `README.md`). It
regenerates `results.md` and `results.json` here. Keep the panel private.
