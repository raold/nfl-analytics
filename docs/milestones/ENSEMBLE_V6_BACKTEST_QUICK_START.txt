→ Start PostgreSQL: docker compose up -d pg

Issue: "R model loading fails"
→ Check models exist: ls models/bayesian/*.rds

Issue: "Backtest stalled"
→ Resume from checkpoint: python py/backtest/historical_validation_v6.py --checkpoint /tmp/ensemble_v6_checkpoint.pkl

Issue: "Out of memory"
→ Increase system memory (16GB minimum)
