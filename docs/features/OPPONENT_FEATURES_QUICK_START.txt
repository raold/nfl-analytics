---

PROBLEM
-------
XGBoost v4 uses DEFAULT opponent features (opponent_epa=0.0, opponent_points_allowed=22.0,
matchup_difficulty=0.0), blocking XGBoost v5 from achieving +2-4 yard improvement.

SOLUTION
--------
4 REAL opponent defensive features computed from rolling 4-week averages:
1. opponent_defensive_epa (EPA allowed per play)
2. opponent_points_allowed (Points allowed per game)
3. opponent_pass_rush_win_rate (% pass plays with sack/QB hit)
4. matchup_difficulty (0-1 normalized difficulty scale)

INTEGRATION WITH XGBOOST v5
----------------------------
# 1. Load player-game data
player_games = load_player_games(season=2024)

# 2. Compute opponent features
engine = OpponentDefensiveFeatures()
opponent_features = engine.compute_features_batch(
    player_games[['game_id', 'season', 'week', 'team', 'opponent']].drop_duplicates()
)

# 3. Merge opponent features
player_games = player_games.merge(
    opponent_features,
    on=['game_id', 'season', 'week', 'team', 'opponent'],
    how='left'
)

# 4. Train XGBoost v5
features = ['player_features...', 'opponent_defensive_epa', 'opponent_points_allowed',
            'opponent_pass_rush_win_rate', 'matchup_difficulty']
X = player_games[features]
y = player_games['yards']

model = xgb.train(params, xgb.DMatrix(X, label=y))

TEMPORAL SAFETY GUARANTEE
--------------------------
ALL features use ONLY games BEFORE target week:

SQL pattern:
  WHERE (season < target_season OR (season = target_season AND week < target_week))

Example: KC vs DEN, 2024 Week 10
  ✅ VALID: DEN games from Weeks 6, 7, 8, 9 (before Week 10)
  ❌ INVALID: DEN game from Week 10 (not yet played)

Verified by _get_recent_games() method
