================================================================================
WHAT IT DOES
================================================================================

HYPOTHESIS:
Categorical tier dummies (Elite/Good/Avg/Weak) beat continuous opponent
metrics for tree-based models.

APPROACH:
1. Load 2018-2024 QB passing yards
2. K-means cluster defenses (k=4) on opp_def_epa_exp + opp_pass_def_rank
3. Create binary tier dummies: def_tier_1, def_tier_2, def_tier_3, def_tier_4
4. Train XGBoost with 20 features (4 tier dummies replace continuous metrics)
5. Evaluate on 2025 test set

FEATURES:
- Core player (10): EPA, CPOE, sack rate, YPA, WR metrics, consistency
- Game context (2): spread, total
- Defensive tiers (4): CATEGORICAL (tier dummies)
- Team features (4): offense EPA, pass rate, pace, success

TARGET:
MAE < 40.20 yards (v2 baseline)

EXPECTED OUTCOME:
- SUCCESS: Tier dummies reduce noise → beat baseline
- FAILED: Continuous metrics better → keep v3.1
