KEY INSIGHTS
--------------------------------------------------------------------------------

1. XGBoost Validation Dominance:
   - XGBoost achieves 0.2050 val Brier vs GNN's 0.2313 (best)
   - Engineered features capture strong signal for validation season
   - Benefits from 18 years of training data (2006-2023)

2. GNN Structural Advantages:
   - No manual feature engineering required
   - Graph structure explicitly models player-team relationships
   - More interpretable: can trace predictions through graph
   - Smaller model (50K vs 100K parameters)

3. Test Performance (GNN only):
   - Best test Brier: 0.2746 (5 message rounds)
   - Test accuracy: 50.2% (slightly better than random)
   - Generalization gap: +0.043 (val to test)

4. Efficiency Tradeoffs:
   - XGBoost: 5 min training, 100K params
   - GNN (Full): 35-45 min training, 50K params
   - GNN (Small): 10 min training, 12K params, only +0.0055 Brier worse

DEPLOYMENT RECOMMENDATIONS
--------------------------------------------------------------------------------

Use XGBoost v3 when:
  - Historical validation data is most important
  - Fast training/retraining is required (5 min)
  - Feature engineering pipeline is already established
  - Validation Brier score is the primary metric

Use GNN when:
  - Interpretability of player contributions is needed
  - Feature engineering bandwidth is limited
  - Graph structure provides domain-appropriate inductive bias
  - Smaller model size is preferred

Use GNN (Small) when:
  - Resource constraints (memory, compute)
  - Fast inference required
  - Minimal performance degradation acceptable (+0.0055 Brier)
