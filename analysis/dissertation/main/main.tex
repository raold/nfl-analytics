\chapter*{Executive Summary}
\addcontentsline{toc}{chapter}{Executive Summary}

\textbf{Can machine learning beat NFL betting markets?} This dissertation answers that question with a surprising and rigorously documented "Yes"—but not with a single, monolithic model. Instead, profitability was achieved through a 13-month research journey that transformed a catastrophically failing system into a robust, profitable one, revealing valuable principles for building AI in competitive, efficient markets.

\paragraph{The Journey from Failure to Profit.}
Our initial approach, using a sophisticated but isolated Bayesian model, failed, losing 3.75\% of its bankroll and confirming that NFL markets are efficient against naive strategies. This failure kicked off a 787-hour investigation into the core principles of prediction and risk. The result was a complete architectural overhaul, culminating in a v6.0 system that is consistently profitable.

\paragraph{What We Built.}
A complete end-to-end sports betting system integrating: (1)~automated data pipelines processing 300,000+ NFL plays; (2)~a diversified 5-way ensemble of machine learning models (State-Space, Hierarchical Bayesian, XGBoost) built on a principle of feature orthogonalization; (3)~a hybrid static-adaptive architecture to balance stability and responsiveness; and (4)~a risk management layer using offline reinforcement learning and portfolio-level constraints.

\noindent\textbf{The bottom line}: A disciplined system built on principles of diversification, feature engineering, and rigorous validation can overcome the 4.5\% transaction cost (vigorish) to generate consistent alpha from public data.

\paragraph{Why This Matters.}
The primary contribution is not a single model, but a \textbf{playbook for building profitable AI in adversarial environments}. We discovered that success hinges on three principles:
\begin{enumerate}[itemsep=0pt,parsep=0pt]
  \item \textbf{Feature Engineering Dominates Model Complexity}: A simple feature orthogonalization technique (our "Ridge Residuals" method) provided an 88\% accuracy improvement, while an 84-hour investigation into complex Bayesian Neural Networks yielded 0\% improvement.
  \item \textbf{Ensemble Diversification > Individual Sophistication}: Adding uncorrelated "weak" models to the ensemble reduced variance and increased profit more effectively than refining a single "strong" model.
  \item \textbf{Radical Transparency Accelerates Progress}: By honestly documenting failures (like the 84-hour BNN dead end), we developed a Bayesian abandonment criterion that prevents wasted effort on low-probability research paths.
\end{enumerate}

\paragraph{Key Insight for Executives.}
\textbf{Profit in efficient markets comes from superior process, not superior complexity.} Our journey proves that consistent returns are not the result of a "black box" algorithm, but a system of systems governed by principles of diversification, risk management, and honest, rapid iteration. This dissertation provides a transferable framework for any organization seeking to build robust, data-driven decision systems in competitive domains like financial trading, supply chain optimization, or resource allocation.

\chapter*{Abstract}
This dissertation presents a system-of-systems for prediction and decision-making that achieves consistent, verifiable profitability in National Football League (NFL) betting markets. The work documents a 13-month research journey, beginning with the failure of monolithic predictive models and culminating in a profitable 5-way ensemble architecture, demonstrating that while markets are efficient against naive approaches, they are vulnerable to a disciplined, multi-faceted strategy.

The final, profitable system is built on three core principles discovered through rigorous experimentation. First, a \textbf{feature orthogonalization methodology} ("Ridge Residuals") based on Gram-Schmidt decomposition is introduced to remove confounding between player skill and opponent strength, yielding an 88\% improvement in component accuracy. Second, a \textbf{diversified ensemble architecture} is employed, combining Bayesian (State-Space, Hierarchical), frequentist (ELO), and machine learning (XGBoost) models. We show that ensemble variance reduction is driven more by minimizing inter-model correlation ($\bar{\rho}=0.32$) than by maximizing individual model accuracy. Third, a \textbf{hybrid static-incremental structure} (70\% static, 30\% incremental) is developed to resolve the stability-adaptation trade-off, achieving a 4.2\% performance gain over pure static or incremental approaches.

These modeling principles are integrated into a full-stack system featuring: idempotent data pipelines on TimescaleDB; dependence-aware pricing models (Skellam, copulas); and a risk-management layer using offline reinforcement learning (CQL) for bet sizing, governed by off-policy evaluation gates and portfolio-level CVaR constraints. Multi-season backtesting (2022-2024) of the final v6.0 system validates a +6.45\% ROI with a Sharpe Ratio of +2.51.

The contributions are twofold: (1) a complete, reproducible, and profitable NFL betting system, and (2) a set of generalizable principles for applied machine learning in efficient markets, supported by a transparent accounting of both successful and failed research paths (e.g., an 84-hour, 0\%-return investigation into Bayesian Neural Networks). This work provides a playbook for moving beyond simple prediction to building robust, profitable, and deployable decision-making systems.

\paragraph{Reproducibility.}
The codebase is designed for full reproducibility. All random seeds are fixed, dependencies are pinned via \texttt{requirements.txt} (Python) and \texttt{renv.lock} (R), and the README provides step-by-step instructions for replicating all results. The experiment registry tracks all model runs with hashed parameters and metrics.

\paragraph{Data Sources.}
Primary data sources include:
\begin{itemize}
  \item \textbf{nflfastR}: Play-by-play data via the R package ecosystem
  \item \textbf{The Odds API}: Historical betting lines (API key required)
  \item \textbf{Meteostat}: Weather data for game conditions
  \item \textbf{NFL official data}: Schedules, rosters, and injury reports
\end{itemize}
