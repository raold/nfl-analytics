\caption{Dual-weight paradigm decision flowchart showing algorithmic routing between v6.0 static weights (game predictions) and v8.0 Dirichlet-learned weights (player props). The paradigm emerged from mechanistic analysis: variance decomposition reveals 84\% within-player variance for props (favoring Bayesian uncertainty quantification via Hierarchical + Priors models) vs opponent interaction dominance for games (favoring XGBoost gradient boosting). Grid search optimization (108 configurations, walk-forward 2022-2024 validation) confirmed the split: XGBoost weight collapses 89\% for props (23\% → 2.6\%) while Bayesian models surge 98\% (40\% → 79.1\% combined). This represents a novel contribution to ensemble methodology: prediction type determines optimal weighting strategy, not component architecture alone.}
