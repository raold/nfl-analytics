\caption[Updated Database ERD with ML Schema]{Updated Entity-Relationship Diagram showing the complete 56-table schema across 5 schemas. The PUBLIC schema contains core tables (\texttt{games}, \texttt{plays}, \texttt{weather}, \texttt{injuries}, \texttt{rosters}, \texttt{odds\_history}). The MART schema provides pre-aggregated materialized views for model training (\texttt{game\_features\_enh} with 170+ columns). The ML schema (new November 2025) supports prediction caching and model management: \texttt{model\_registry} tracks 337 models, \texttt{r\_model\_predictions} caches 6,090 R model predictions for 200-400x speedup, and \texttt{ab\_test\_*} tables track Dirichlet weight experiments. Total database size: 2.8 GB with 1.25M plays across 7,263 games.}
