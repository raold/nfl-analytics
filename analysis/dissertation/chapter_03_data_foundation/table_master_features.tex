\paragraph{Feature Temporal Safety.}
Features marked \texttt{asof\_safe} (\checkmark) are guaranteed to use only information available before game kickoff. All 232 features (186 baseline + 120 Phase 2 advanced analytics) are validated by 15 unit tests and 2 runtime validators (see Appendix~\ref{app:leakage_audit}). The 7 unsafe features (\ding{55}) are post-game outcomes used only as training targets or evaluation metrics, never as predictors. Coordinator continuity features (OC+DC, 16 features) are derived from the \texttt{coaching\_staff} table with temporal joins ensuring season-year as-of semantics. Phase 2 advanced analytics features (\Cref{sec:phase2-advanced-stats}) add cutting-edge NFL tracking data and efficiency metrics with 100\% temporal safety validation.

\paragraph{Feature Engineering Rationale.}
The feature catalog balances three principles:
\begin{enumerate}
    \item \textbf{Temporal safety}: Strict as-of semantics prevent leakage (validated by automated audit)
    \item \textbf{Interpretability}: Each feature has clear definition, calculation method, and domain motivation
    \item \textbf{Redundancy control}: Rolling windows (last 3/5 games) provide recent signal while expanding averages capture long-term trends
\end{enumerate}

For detailed definitions of all 232 features (186 baseline + 120 Phase 2 advanced analytics), see the feature catalogs at \texttt{py/features/catalog.yaml} (baseline) and Phase 2 module documentation in \Cref{sec:phase2-advanced-stats}. Key ablation results showing the marginal contribution of each family are presented in \Cref{tab:ablations} (Chapter 4).
